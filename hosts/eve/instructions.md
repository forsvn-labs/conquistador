Read the request and available context. State the intended outcome in one sentence. Ask at most
one bundled question, and only when a material choice cannot be inferred. Then do one of:

- launch or grow this;
- create or improve marketing work;
- learn from these results.

file is not an executable playbook.

## Approval

Ask for a human with authority immediately before any send, publish, spend, credential use, or
other external write. If this Eve app has no approval tool for that action, leave a ready-to-use
draft and stop.

schedules, hooks, the Conquistador runner, or the typed catalog. If those are absent, say so and
degrade to a draft. Do not invent sibling skills that are not on disk.

# Conquistador

Marketing and growth playbooks for coding and deployed agents. Your agent
supplies the model and runs the work.

With Node 22.18 or later, install and open the CLI:

```sh
npm i -g @forsvn/conquistador@latest && conquistador
```

[Choose an installation method](https://conquistador.app/install), read the
[usage guide](https://github.com/forsvn-labs/conquistador/blob/main/docs/USAGE.md)
and [command reference](https://github.com/forsvn-labs/conquistador/blob/main/docs/README-REFERENCE.md),
or use [CONTRIBUTING.md](https://github.com/forsvn-labs/conquistador/blob/main/CONTRIBUTING.md)
to build and test the source.

- [VISION.md](https://github.com/forsvn-labs/conquistador/blob/main/VISION.md): users, intended outcomes, and boundaries.
- [BRAIN.md](https://github.com/forsvn-labs/conquistador/blob/main/BRAIN.md): external knowledge key and access.
- [STRUCTURE.md](https://github.com/forsvn-labs/conquistador/blob/main/STRUCTURE.md): source architecture and navigation.
- [STATUS.md](https://github.com/forsvn-labs/conquistador/blob/main/STATUS.md): verified state, blockers, and next steps.

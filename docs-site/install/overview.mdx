Choose how you want to reach Conquistador. All four methods use the same playbooks.
[The installation page](https://conquistador.app/install) offers the same choices.

Start the reviewed installer with Node 22.18 or later:

```sh
npx conquistador@latest
```

Use `bunx conquistador@latest` or `pnpm dlx conquistador@latest` if preferred.
For a permanent command, run `npm i -g conquistador`.

## Skills

```sh
npx conquistador@latest skills
```

One project skill folder, without hooks or MCP. The Conquistador installer supports agent selection and previews every change.

## CLI

```sh
npx conquistador@latest install
```

Choose coding agents, review changes, then install. Use `--providers=claude,codex` to preselect
clients and `--dry-run` or `--json` to preview. Use `conquistador install-cli` to keep the command.

For deployed agents, add the [production app dependency](/install/app). Imports start no UI,
agent, or listener. Your app owns the model, user context, and access rules.

## MCP

For local stdio clients:

```sh
npx conquistador@latest mcp
```

`conquistador mcp install --apps=zed,vscode` configures selected desktop clients after review.
No HTTP bridge is required. See [standalone MCP](/install/mcp-apps) for coding agents,
Executor, and Composio. Remote apps need a public HTTPS deployment with verified authentication.

## Plugins

```sh
npx conquistador@latest plugins
```

Choose Claude Code, Codex, Grok, Cursor, or Copilot CLI. Each uses its own plugin mechanism.
Other compatible clients can use the prepared plugin bundle from the
[release assets](https://github.com/forsvn-labs/conquistador/releases).
Hooks and MCP support depend on the client. A shared format does not guarantee every feature.

## Install without questions

```sh
conquistador skills --providers=codex --yes --plain
conquistador install --providers=claude,codex --dry-run --json
conquistador mcp install --apps=zed,vscode
```

The advanced installer keeps `--surface`, `--executor-name`, and `--bot-out` for existing
workflows. They stay in the [CLI reference](/reference/cli) and the packaged INSTALL.md.
These options do not add new public installation methods.

## Maintenance

Run `conquistador doctor`, `conquistador update`, or `conquistador remove`. Existing advanced
flags and [bot exports](/install/chat-bots) remain available without becoming separate setup
methods. Installation starts no agent task. Your agent supplies the model.

The four routes require 0.8.0 or later. The short-name `conquistador` CLI package pins the
matching `@forsvn/conquistador` release; both names use the same installer.
See the repository [handoff](https://github.com/forsvn-labs/conquistador/blob/main/ROADMAP.md).

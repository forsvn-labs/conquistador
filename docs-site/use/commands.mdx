A command is one method for one job. The MCP tools call commands "methods" (`conquistador_methods`). Type `/conquistador <command> [target]`, or describe the job and let the router pick.

```text
/conquistador position against the two biggest competitors
/conquistador ads results from last month's Meta campaign
/conquistador check landing/index.html
```

## How a command finds its playbooks

1. **The brief** picks the command or play and ranks the playbooks for the task. A named platform, for example TikTok or Google Ads, brings its platform guide and leaves the others out.
2. **The MCP tool** `conquistador_brief` returns the selected playbooks inline.
3. **The prompt hook** adds the must-read list to marketing prompts. Coding prompts get nothing.
4. **The stop hook** checks the transcript. If the agent answered without reading the must-read files, the hook sends it back once to read them and revise.

Each command also lists its playbooks in its `COMMAND.md`, so an install without hooks still points the agent at the right files.

## Old names

Old skill names still route to their commands, for example `write-copy` to `copy` and `launch-product` to `launch`. See [MIGRATION.md](https://github.com/forsvn-labs/conquistador/blob/main/MIGRATION.md).

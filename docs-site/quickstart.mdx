This page uses a coding agent, for example Claude Code or Codex. For other places, see [Install options](/install/overview).

## Before you start

- Node 22.18 or later. Check with `node --version`.
- A supported coding agent, signed in.

You do not need an account for a marketing service. The agent drafts from the facts that you give it.

## 1. Install and open Conquistador

In your project folder, choose npm or Bun:

```sh
# npm
npm i -g @forsvn/conquistador@latest && conquistador

# Bun
bun add --global @forsvn/conquistador@latest && conquistador
```

This installs the permanent command and opens the full-screen TUI. It finds your agents,
shows the plan, and changes no agent configuration until you confirm. It ends with the command
to type in each agent. The terminal installs Conquistador; the work happens inside your agent.
See [Coding agents](/install/coding-agents) for the steps.

Run `conquistador` later to manage your installs. To run the installer once instead:

```sh
npx @forsvn/conquistador@latest
bunx @forsvn/conquistador@latest
pnpm dlx @forsvn/conquistador@latest
```

You can keep the command later with **Keep the CLI installed** in the TUI.
Use `-g` with npm. Without it, npm installs into the current project. See
[Troubleshooting](/troubleshooting#npm-install-without-g) if an older command runs.

## 2. Record your product

Open your agent in the project. In a project without `PRODUCT.md` and `GROWTH.md`, the installer's last screen tells you to type this command:

```text
/conquistador init
```

`init` reads the project, asks only about gaps (at most three questions per round), and writes `PRODUCT.md` and `GROWTH.md`. Every later command reads these files.

## 3. Run a task

Name a command, or describe the task in plain words:

```text
/conquistador outreach churned customers
/conquistador launch
/conquistador write a win-back email flow for trial users who never activated
```

The agent reads the playbooks for the task, writes the deliverable, and ends with "Playbooks applied": each file and the rule it took from it.

## 4. Check the copy

```sh
conquistador check marketing/
```

Exit code 0 means no errors or warnings; advisory notes can still print. Exit code 2 means errors or warnings. Exit code 1 means a file could not be read or scanned. In Claude Code, Codex, and Cursor, a hook runs the check after the agent edits a marketing file. See [Copy check](/check).

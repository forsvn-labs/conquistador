# Setup UI dependency

Clack prompts 1.8.1 is bundled into `../vendor/clack.mjs`. This folder is a maintainer build
boundary. Neither the project installer nor source/ZIP setup runs npm here.

```sh
npm ci --ignore-scripts --prefix tools/tui
npm run build --prefix tools/tui
```

Review the lockfile, generated bytes and `../vendor/NOTICE.txt` after a dependency change.
The bundle uses only native Node APIs at runtime. Build-only esbuild and node_modules are not
part of a committed source archive or the installed project payload.

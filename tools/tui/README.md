# Terminal UI bundles

`build.mjs` bundles the terminal UI libraries into `../vendor`, so installs need no npm dependencies:

- `clack.mjs`: Clack prompts 1.8.1, the line prompts for `conquistador setup`.
- `ink.mjs`: Ink 8 and React 19, the full-screen installer in `../installer-tui.mjs`.
- `NOTICE.txt`: the license of every bundled package, written by the build.

This folder is a maintainer build boundary. Neither the installer nor source/ZIP setup installs
packages here.

```sh
cd tools/tui
bun install --ignore-scripts
bun run build
```

Review `bun.lock`, the generated bytes, and `../vendor/NOTICE.txt` after a dependency change. The
bundles use only Node APIs at runtime. React DevTools is replaced with a stub (`devtools-stub.mjs`).

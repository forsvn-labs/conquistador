# Adapt the offer to the chosen format

Choose a format based on the evidence it can show, asset rights, production cost,
and placement constraints. Retain the same offer and approved claims when adapting
it. A format change is a test variable, not a presumed algorithm advantage.

| Format | Required brief |
|---|---|
| Demonstration video | Task, visible actions, actual output, limitations, audio and captions |
| Creator presentation | Consenting narrator, relationship disclosure, permitted words, usage rights |
| Static image | Legible product fact, image provenance, terms, destination action |
| Animation | Sequence showing the process; distinguish illustration from measured output |
| Explanatory pre-lander | The unanswered question, evidence to present, sponsorship, offer terms, onward action |

A truthful UGC concept uses a real consenting actor and discloses affiliation.
Label scripted or representative scenes. Never manufacture a personal history,
medical opinion, testimonial, or spontaneous reaction. AI-generated depictions
must not imply an actual customer's experience.

If an explanatory page is needed, specify what the ad cannot explain accurately
in the selected placement. Show material offer terms without concealing price to
force another click. Brief the page's evidence and onward CTA. Do not require a
fixed persuasion sequence or discredit alternatives without comparative evidence.

Every motion brief includes a still or poster fallback, captions, and a
reduced-motion version carrying the same proof and action. Use supplied approved
brand examples through realized-surface-grounding.md, or record their absence.

List each changed element across variants. For a controlled test retain the
reference's other elements. For exploratory concepts, state that the result only
compares bundles; a follow-up test must isolate the suspected cause.

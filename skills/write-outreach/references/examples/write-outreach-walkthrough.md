# Worked drafting decisions

All inputs here are synthetic. No messages were sent, no recipient was contacted, and no performance
was measured. The example shows a reasoning path, not a transcript of a model or specialist run.

## Input and evidence

An operator requests one no-pitch research email about handoff practices. They supply a permissioned
note, S1: “We keep handoff owners in a shared document.” Permission covers quoting that sentence.
No seller result evidence is supplied or needed. The sender is building a product and must say so.

The signal pass can establish only the documented practice. It cannot infer lost work, frustration,
budget, or desire to buy. The strategy pass chooses one current-behavior question: how an ownership
change is recorded. The proof pass rejects any claim that the sender's product solves this problem.

## Complete draft

Subject: Recording a handoff change

You described keeping handoff owners in a shared document. I am researching that practice for a
product project. How do you record a change of owner today? No need to reply; I will not follow up.

## Review

The observation maps to S1; the question does not presume failure. Affiliation and purpose are
visible. One answer is requested, and no further contact is implied. Review under the shared rubric
can mark this targeted READY only for the supplied synthetic evidence. Actual action still needs
recipient, account, exact payload, timing, and sender approval; this example supplies none of those.

If S1 is removed, remove the observed-person opener and label the remaining draft a generic
NEEDS_SIGNAL template. Do not invent a source to preserve the wording. If the user changes the
purpose to sales, disclose that purpose and review the proposed offer and claims afresh.

## Reply branch

acknowledgement only if appropriate, plus a separate proposed suppression action for the operator.

# Professional-network messages

Distinguish a connection note from a direct message. Use the current host limit if verified; otherwise flag length for checking. Do not promise preview behavior or truncate qualifications to fit a supposed limit. A connection acceptance does not establish consent for a sequence.

## Pre-action checks

Avoid irrelevant profile details and unsupported familiarity. Mark any missing source or platform rule. Do not connect, enrich, scrape, or message as part of drafting.

Return the complete draft with relevant gaps under [format conventions](../format-conventions.md).
Use the common claim and recipient-control gates; a channel does not waive them. Character counts
can describe the draft itself, but unverified platform limits must not be asserted as current facts.

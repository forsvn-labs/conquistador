# Arrange a message for its actual task

A message has no required sentence order. Place the information needed to interpret the next
sentence before that sentence. Keep the affiliation visible when omission could mislead.

- For a sourced observation, separate the observed fact from the possible implication.
- For a proposed service, explain scope and exclusions before asking for a commitment to it.
- For research, state the purpose and ask one question about behavior, not approval of the product.
- For a proposal response, address the recipient's stated requirements and unresolved dependencies.
- For a reply, resolve the inbound question first. Do not restart the first-touch pitch.

Read the message without the opening. If the remaining request is unrelated to the signal, repair
the reasoning or drop the signal. This is an evidence check, not a rule requiring every opener.
Read it without the closing. If the requested next step is missing, add one clear question or action.
A refusal or acknowledgement may correctly contain no new request.

Follow-ups must name a new, truthful reason to contact the person. Never imply that silence creates
a debt, a prior conversation, or agreement. Stop at the operator's authorized boundary and on opt-out.

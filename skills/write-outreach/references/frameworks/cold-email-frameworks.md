# Choose the information the reader needs

Use this reference to resolve a drafting choice, not to assign a persuasion formula or stereotype
readers by seniority. Start from what the user actually knows about this recipient and request.

| Evidence state | Useful drafting choice | What must remain uncertain |
|---|---|---|
| Recipient described a problem | Refer accurately to that description and ask whether the proposed work is relevant | Whether the problem is still active |
| Sender has a relevant capability, no recipient signal | Describe the possible use case conditionally | Whether this recipient has that need |
| Recipient requested proposals | Answer the stated requirements with scope and exclusions | Any requirement not specified |
| Research question, no commercial claim | Disclose the research purpose and ask about actual practice | The recipient's experience and answer |
| Recipient already replied | Answer their question or respect their decision | Interest beyond what they expressed |

An alternative draft is useful only when it tests a different unresolved decision, such as whether
the reader needs scope or evidence first. Explain that difference. Do not generate variations that
merely swap adjectives. Compare drafts for factual accuracy, necessary context, and ease of reply;
response performance remains unmeasured until a real, authorized test.

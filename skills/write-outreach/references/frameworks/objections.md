# Respond to what the recipient actually said

Use the inbound message as evidence. Do not assume an objection hides interest. Record its meaning,
confidence, any requested action, and the narrowest useful response.

| Inbound | Response | Stop boundary |
|---|---|---|
| No interest / remove me | Acknowledge briefly if needed; record required suppression for operator action | No revised pitch |
| Not now | Respect timing; ask about a later contact only if their wording invites it | No invented future consent |
| Wrong person | Thank them; accept a volunteered referral | No demand for a colleague's private details |
| Evidence requested | Supply only relevant, permitted evidence with limits | No invented case study |
| Price or scope question | Answer known terms, identify unknowns | No unauthorized discount or guarantee |
| Existing supplier | Acknowledge; answer any actual question | No unsupported competitor claim |
| Ambiguous response | Ask one clarifying question if appropriate | No automatic interested classification |
| Sensitive information offered | Suggest an approved safe channel if needed | Do not solicit secrets in the thread |

A hostile reply does not need persuasion. Keep any acknowledgement brief and stop. If the recipient
requests a contractual, legal, or security assurance outside the sender's authority, return the
question to the operator instead of inventing an assurance. Never modify CRM or suppression state
merely because a response draft says it should happen; distinguish proposed action from completed action.

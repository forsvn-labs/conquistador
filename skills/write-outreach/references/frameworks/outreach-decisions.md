# Decide what makes this message worth reviewing

Use this worksheet when a commercial message is proposed. It is a local drafting procedure, not a
claim that a particular structure causes responses. Research follows its own intent boundary.

## 1. Test the selection explanation

Write the evidence that caused the sender to select this recipient. Then write the inference
separately. If the evidence is merely a job title, use a conditional situation rather than an
observation. If it reveals sensitive personal circumstances, omit it and reconsider selection.
A recipient should not have to correct an invented premise before answering the request.

## 2. Define the exchange

Describe what the sender can actually provide, what participation requires, and who benefits.
A proposed review is not a completed review. A free offer still costs recipient attention and may
create obligations; disclose those. Do not invent guarantees, scarce availability, social approval,
or authority. If there is a fee or a sales purpose, do not disguise it as neutral research.

## 3. Set a claim boundary

For each result, record the source and conditions. Use a narrower capability statement when the
source does not establish a result. Remove superiority language unless the comparison is supported
on the relevant dimension. Do not generalize one customer's outcome to all prospects.

## 4. Choose what the recipient can decide now

Ask for the smallest answer that meaningfully advances the stated purpose. A meeting can be a
reasonable request when discussion is needed; a short reply can be more suitable when one fact is
missing. Neither is universally better. State the next commitment accurately and allow refusal.

## 5. Draft and challenge the rationale

Arrange the needed facts in a readable order. Ask: could a reasonable recipient understand why
this arrived, what is claimed, and what happens if they answer? If not, revise the missing fact.
Do not compensate with flattering language, pressure, or a longer sequence.

Return selection rationale, proposed exchange, claim boundaries, one recipient decision, draft,
and unresolved checks. For no-pitch research, omit the commercial exchange and use the
[research mode](../modes/no-pitch-research.md).

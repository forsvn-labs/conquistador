# Review evidence scope

This skill assesses claims against the sources available for the current review. Its instructions
and rubric define review obligations; they do not establish that a claim is true or that a human
has approved it.

## Record the evidence actually inspected

For each source, record its exact path or citation, date, access route, and a digest where possible.
State which claim it supports and whether you inspected the full source or only an excerpt. Keep
reported provenance separate from provenance you can verify. If origin, access, or freshness is
unknown, record that limitation beside the affected claim.

Do not infer unavailable source contents from a title, a reference, or another review's verdict.
Request the missing material when it could change the decision. Otherwise, explain what remains
unresolved and set a date, event, or condition for rechecking it.

## Distinguish review from approval

A counter-read in the same context can expose weaknesses but is not independent corroboration.
Claim an independent review only when a separate context actually ran, and identify its evidence.
A completed rubric records review quality. It does not approve the underlying claim, publication,
action, or release. Any human decision must be recorded separately with its actual scope.

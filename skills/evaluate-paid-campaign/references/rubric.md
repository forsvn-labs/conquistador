# Paid evaluation review rubric

Score each dimension 0-10. A missing or contradicted contract receives 0; a material
error receives 1-5; a usable, explicitly limited result receives 6-7; complete,
inspectable evidence and reasoning receive 8-10. Cite the actual artifact.

| Dimension | Required check |
|---|---|
| Loop fit | Source hypothesis, scope, and next decision are clear; standalone use is supported |
| Metric integrity | Units, counts, denominators, windows, provenance, and missing values are correct |
| Attribution honesty | Event lag, overlap, cohort maturity, and causal limits remain visible |
| Decision discipline | Agreed loss and information rules govern the verdict without retrospective tuning |
| Audience fidelity | Network, eligibility, and comparison scope agree |
| Fatigue awareness | Exposure changes receive competing explanations and a discriminating test |
| Ledger correctness | Artifact, precise action, compatible row, provenance, and learning scope agree |

The existing local review interface requires at least 49/70 and every dimension
at least 6. A score does not measure statistical confidence or actual lift.
Hard blockers override totals: fabricated data, unsplittable cells described as
comparable, missing denominators hidden by a rate, unsupported causality, an ignored
loss limit, or an action outside authority.

Confidence requires a reason tied to the agreed evidence requirement and the
verdict's sensitivity. Dollar spend, impressions, frequency, and elapsed days do
not create confidence by crossing a built-in threshold. An operational pause may
be justified while the performance question stays inconclusive.

Check optional learning promotion separately. Retain account, audience, offer,
period, uncertainty, and expiry. No universal benchmark may be promoted from this
cycle. Return the precise defect and needed evidence, not a generic score alone.

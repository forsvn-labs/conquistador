# Sequential fallback

Use when the host cannot run crawl, foundations, content, authority, AI, programmatic, ASO,
prioritization, critic, or evaluation specialists as separate agents.

Keep the same method. Change only the machinery.

Name the search mode first: technical web, answer visibility, programmatic, comparison pages,
app-store, or evaluation readout. Do not run every agent. Prefer one decisive correction.

## Diagnosis / correction

1. Confirm crawl, render, index, and canonical eligibility with `agents/crawl-agent.md` and
   `references/technical-crawler-checklist.md` before any citation or content play.
2. Run only the agents for the chosen mode, as sequential passes:
   - technical: crawl, foundations, content-quality, authority;
   - answer visibility: ai-structure, ai-presence, plus
     `references/platform-intelligence/bing-readiness.md` and
     `references/geo-citation-readiness-checklist.md`;
   - programmatic: programmatic-template, programmatic-quality;
   - comparison: comparison-page;
   - app-store: aso-keyword, aso-listing, aso-reviews, aso-competitive.
3. Rank with `agents/prioritization-agent.md` (impact × effort, dependencies first).
4. Gate with `agents/critic-agent.md`. Every recommendation names exact page, exact change, and
   expected impact. Tag retrieval and citation claims with `references/evidence-classes.md`.
5. Load `references/anti-patterns.md` before ship.

## Evaluation readout

Use this lens after a prior search change, not to invent a new SEO plan.

1. Normalize metrics with `agents/eval-metric-ingest-agent.md`. Missing data is missing, never zero.
2. Diagnose with `agents/eval-diagnosis-agent.md` against the original hypothesis and lag floor.
3. Recommend keep / discard / watch / blocked with `agents/eval-recommendation-agent.md`.
4. Gate with `agents/eval-critic-agent.md` and `references/eval-rubric.md`. A short window or
   core-update confound cannot become `keep`. Impression and keyword-count vanity cannot become
   success.
5. Append one ledger row on the measurement artifact. Do not run TypeScript helpers.

Label this single-context. Do not call it independent corroboration. Never promise rankings,
citations, traffic, or an indexing timeline. Deployments, index requests, and account changes stay
behind explicit human approval.

# Campaign critic

Review the assembled plan against the user's requested scope. Return PASS or FAIL
with exact evidence, repair, and responsible role. A bounded parent composition
needs only its requested audience/job, value exchange, placement, economics,
capacity, signal, guardrails, stop rule, and authority boundary. Full banks,
channel scans, timelines, and narration are N/A unless requested.

## Full-plan checks

| Check | Required evidence | Repair owner |
|---|---|---|
| Foundation | Campaign outcome, actual reader decisions, sources, and assumptions | Orchestrator |
| Pillars | Each theme serves a named task with product or audience evidence | Pillar agent |
| Angles | Each promise has a parent, permitted proof, reader decision, and useful next action | Angle agent |
| Selection | Priorities explain tradeoffs; unsupported claims cannot pass by score | Angle agent |
| Channel assignment | Specific angle and evidence of access/fit, or a labeled test need | Channel agent |
| Destination | Promised action works or the unresolved prerequisite blocks activation | Channel agent |
| Capacity | Per-owner effort, production/review dependencies, and available time agree | Timeline agent |
| Sequence | Activation follows explicit readiness and action approval | Launch sequencing agent |
| Measurement | Primary outcome, diagnostics, review window, confounders, and stop conditions | Orchestrator |
| Traceability | Every scheduled angle/channel exists in the selected plan | Earliest affected role |
| Authority | Human acceptance and exact external-action approval remain separate | Orchestrator |

Stage and Trigger are free-form task context and observed events. Do not require
knowledge-level proportions, emotion assignments, a minimum pillar/angle count,
a /25 score, fixed phase count, or mandated activation order. Informational content
can pass. A capacity mismatch needs actual effort evidence, not a team-size quota.

## Method and evidence checks

Use the channel owner's legibility-convention.md. A method-only pack has
last_verified: null; pack_verified remains none and method_updated is separate.
A missing current rule is a verification gap, not a stale ranking formula to reuse.
Pack §0 raises fit questions, §1 helps choose an opening, §2 records task-verified
constraints, §3 names observable measures, §5 defines a test, §6 covers capacity
and timing, and §7 covers CTA. Reject claims of automatic rank or expected lift
based on those method sections.

Require truthful per-channel verification notes and the campaign's Why This Works
rationale before Review Gate. Explain product choices with actual sources and
uncertainty. Missing evidence may permit a provisional plan with blocked activation;
fabricated proof or a false claim of readiness fails.

For FAIL, name the component, exact defect, consequence, smallest repair, and role
to rerun. Re-run downstream dependencies when inputs change. Limit revision to two
cycles, then return unresolved issues with the best plan. A PASS measures the plan's
coherence; it does not establish campaign performance or authorize live action.

# Worked campaign plan

This invented example demonstrates the method. It is not a live campaign, provider
call, or measured customer result. Its resource estimates are local example inputs.

## Brief and foundation

A fictional appointment tool needs prospective users to complete an import preview.
The operator supplies a local demonstration, duplicate-handling specification,
existing product page, and access to one owned newsletter. The request is a closed
campaign slice. The owner has four production hours available before review.

The reader must decide whether to preview an existing appointment list and how to
handle duplicates. No audience stage percentages or emotional profile are supplied
or inferred. The evidence supports product behavior but no time-saving comparison.

## Pillar and angle decisions

For illustration, the planner records two possible task themes from ../examples.md.
Only the import-preview angle is activated in the bounded slice; a complete angle
bank is not required. The duplicate reference remains deferred because producing
both would exceed the supplied capacity.

The selected angle promises a preview before confirmation. Its opening shows that
screen, its proof is the actual demonstration step, and its next action is opening
the import preview. The comparison claim that it is faster than all alternatives
is rejected because no comparative test exists.

## Delivery plan

The newsletter is the supplied closed channel. The planner does not expand to nine
channels or prescribe a public launch ladder. The execution brief records the exact
angle, audience eligibility, current consent and suppression checks, destination,
owner, production effort, and review point. Any missing format or permission input
remains unresolved. Loading a newsletter method pack keeps pack_verified:none;
method_updated records the method date separately from task verification.

The schedule follows production, claim/permission review, destination check, exact
send approval, and later measurement. Those are work dependencies, not reader
psychology stages. No send occurs during planning. The duplicate-handling asset can
be added later when time and evidence support it.

## Measurement

The primary outcome is completed import previews for the declared cohort. The
brief records event definition, denominator, attribution window, reporting delay,
and the decision rule supplied by the operator. If a baseline or target is missing,
return a measurement prerequisite and a bounded pilot proposal rather than an
invented newsletter or conversion benchmark.

## Critic and handoff

Critic checks evidence, task relevance, the selected angle, capacity arithmetic,
destination readiness, traceability, and authority. It does not fail the bounded
slice for missing themes, emotional labels, a minimum score, or a five-stage ladder.
If a claim or permission remains unsupported, the plan is provisional and that
activation stays blocked.

Return the scoped plan and one human decision. For a full campaign use the section
and table contract in ../format-conventions.md. Route finished newsletter writing
to the appropriate copy skill with the same offer, evidence, and controls. Planned
outcomes must not appear in a later evaluation as observed measurements.

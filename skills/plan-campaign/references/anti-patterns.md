# Campaign planning failure checks

| Defect | Check and repair |
|---|---|
| Imposed reader model | Replace mandatory stages or emotion assignments with sourced tasks, questions, and unknowns |
| Invented audience proportions | Require actual measurement or remove the percentages |
| Theme quota creates filler | Retain only pillars with relevant decisions and evidence |
| Angle without a parent | Link it to an existing pillar or revise the theme record first |
| Score hides a blocker | Reject unsupported claims before assigning ordinal priority |
| Invented customer voice | Use exact permitted quotations or label a hypothetical question |
| Automatic channel behavior | Replace ranking/benchmark assumptions with scoped evidence and test criteria |
| Method date is called verification | Keep pack_verified:none for method-only use and record method_updated separately |
| Scope expansion | Respect a closed candidate set; mark full-plan banks and scans N/A for bounded slices |
| Cadence from headcount | Calculate production/review effort against actual available time |
| Psychological timeline | Sequence real dependencies; no compulsory content mix or buyer progression |
| Fixed activation order | State readiness, access, ownership, and approval for each channel |
| Unsupported cross-channel copy | Verify the actual format and audience task before adapting assets |
| Missing offline requirements | Include selected IRL/OOH/vendor/capture or SMS consent/suppression needs |
| Unmeasurable plan | Name the qualified outcome, observation requirement, guardrails, and stop rule |
| Premature execution claim | Keep Planned distinct from evidenced Live/Done |
| Approval drift | Separate critic result, human content review, and exact action authority |

Run pillar generation before angles. Run channel assignment before timeline and
activation sequencing. Re-run downstream roles when their inputs change. Missing
context is a named limitation or focused question; do not invent source evidence
or automatically expand into a new research project.

Check source relevance to the current offer and audience rather than using a fixed
age cutoff as proof of accuracy. Explain material changes and uncertainty. Detailed
budget calculations and individual assets belong to their specialist skills.

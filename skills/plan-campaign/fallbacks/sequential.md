# Sequential campaign planning

Use one context when independent specialist agents are unavailable and label it
accurately. Preserve the dependencies and checks, not a claim of independent review.

For a bounded parent request, use only its supplied channel set and requested job,
value exchange, economics, signal, guardrails, stop rule, and human activation
boundary. Full pillar/angle banks, an open channel comparison, launch phases, and
narration blocks are N/A unless requested. Do not expand the assignment.

For a full plan:

1. Resolve product, audience tasks, campaign outcome, growth motion, constraints,
   evidence, capacity, and deadline. Ask only about material missing inputs. Mark
   provisional assumptions and changed or irrelevant research; no fixed age cutoff
   establishes whether an audience claim is usable.
2. Run agents/pillar-agent.md, then agents/angle-agent.md with
   references/3d-angle-framework.md. Generate evidence-backed decisions and angles;
   no compulsory stage ladder, emotion matrix, count, or /25 cutoff applies.
3. Run agents/channel-agent.md with references/channel-strategy.md and
   references/platform-channels.md. Preserve a closed candidate set; otherwise
   account for the nine channel families. Load relevant platform method packs.
4. Use pack §0 fit, §1 opening, §2 task-verified constraints, §3 observable measures,
   §5 test, §6 capacity/timing, and §7 CTA. Apply references/legibility-convention.md.
   Method-only packs have last_verified:null and a separate method_updated date;
   pack_verified stays none. Do not import ranked signals or benchmark defaults.
5. Run agents/timeline-agent.md and agents/launch-sequencing-agent.md from actual
   dependencies, effort, destination readiness, and action authority. Distribution
   plays require task fit, permissions, economics, and measurement prerequisites.
6. Assemble references/format-conventions.md with product rationale per
   references/why-this-works-convention.md. Run agents/critic-agent.md and
   references/anti-patterns.md. Repair from the earliest affected role, at most two
   cycles, then retain unresolved issues with the best draft.
7. Return the plan inline or write the existing campaign-plan.md path when the
   store exists. Keep human Review Gate last and leave reviewer/date empty until
   a human response arrives. Review does not authorize external action.

A fast request reduces candidate volume to feasible useful work; it does not skip
evidence, capacity, or approval checks. Budget arithmetic, actual copy production,
and measurement of a live campaign go to their dedicated skills.

# Stress-test the proposed funnel

Receive the model, target, assumptions, constraints, and evidence. Apply [stress tests](../references/stress-tests.md). Recalculate downside, base, and upside cases with explicit inputs and inspectable arithmetic.

Return Scenario results, Binding constraints, Decision-sensitive assumptions, and Recommended next evidence. Record any missing capacity or cost input. Do not insert a standard percentage or industry threshold to fill a gap.

Explain which alternative remains feasible and why. If none does, return the constraint and a revised scope, target, or evidence step. Separate assumptions from observations and keep spending and external changes behind human authority.

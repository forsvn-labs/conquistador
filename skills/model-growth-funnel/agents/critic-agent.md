# Review the funnel decision model

Receive the brief, completed model, evidence, scenario results, and constraints. Evaluate these four areas:

1. Definitions and arithmetic: compatible units, cohorts, periods, explicit formulas, and correct calculations.
2. Evidence and assumptions: observed baselines have sources; missing values and scenario assumptions are visible; comparisons do not masquerade as baselines.
3. Feasibility: capacity, timing, cost, and applicable user constraints support the proposed recommendation or an explicit no-go conclusion.
4. Decision usefulness: alternatives, sensitivity, next evidence, owner, and review trigger allow the user to act within their authority.

Return PASS when no material defect remains, or FAIL with the location, consequence, and required correction. Route definitions to model selection, measurements to baseline collection, target assumptions to target setting, and sensitivity or capacity to stress testing.

An unknown metric is not automatically a failure if the recommendation is explicitly bounded by it. An invented value is a failure. Never compensate for an unsupported assumption by assigning a favorable score elsewhere.

Recheck affected calculations after correction. A PASS concerns the model's integrity and usefulness. It does not certify a forecast or authorize a campaign, purchase, or live-system change.

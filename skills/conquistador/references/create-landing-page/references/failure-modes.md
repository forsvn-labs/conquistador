# Diagnose the page before prescribing a change

Use the actual brief or implementation as evidence. A stylistic preference alone is not a conversion
failure. Record location, observed issue, likely consequence as a hypothesis, and smallest repair.

- **Offer unclear:** quote the ambiguity; state the real offer and intended task without a stronger promise.
- **Claim unsupported:** identify the source gap; narrow or remove the claim, not its qualification.
- **Action misleading:** compare label with actual destination; disclose the real commitment.
- **Unnecessary collection:** identify fields with no current purpose; remove or defer them.
- **Evidence misplaced:** name the question it should answer; move only if it improves access to that answer.
- **Reading order broken:** describe the dependency and proposed order; verify in the built target later.
- **Concern unanswered:** distinguish an observed question from an assumption; supply a supported answer or limit.
- **Missing asset:** show a safe fallback or remove the slot; never generate proof of a customer.
- **Unrun behavior asserted:** replace the claim of success with an acceptance criterion and owner.
- **Result unknown:** propose a test appropriate to the available evidence; do not fill results with predicted lift.

Use LP check IDs from [the review method](conversion-principles.md). No fixed field count, sentence
length, proof age, or visual height establishes effectiveness. Report unavailable evidence and scope
limits. Implementation, traffic changes, and publication remain separate authorized actions.

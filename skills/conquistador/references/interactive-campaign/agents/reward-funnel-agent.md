# Agent — Value & Funnel

**Role:** Make the interaction useful and sustainable, then connect it to an honest next step.

## Input
- The mechanic + offered value + placement + capture mode + goal metric.

## Method
1. **Value and cost.** Name what the participant receives and model the variable cost at the bounded
   test volume. Only prize-based mechanics need tiers, odds, redemption caps, and prize economics.
2. **The value exchange.** Keep the useful takeaway available before conversion. If data capture is
   justified, ask only for what the promised follow-up needs and state why. If capture is absent,
   say so.
3. **Compliance check.** Flag privacy, consent, age, accessibility, or jurisdiction questions that
   actually apply. Add sweepstakes or lottery checks only when chance and something of value exist.
4. **The next step out.** The interaction ends with its useful result and, when the goal needs one, a
   proportionate optional CTA. A pure-awareness or research interaction may end at the result when
   that boundary is explicit; do not manufacture an offer or capture step.
5. **Measurement hooks.** Define exposure, start, completion, meaningful outcome, optional capture,
   qualified next action, and the relevant quality guardrail.

## Output
Value and cost model · optional capture point · applicable compliance flags · funnel · measurement
hooks. Add prize-specific fields only when the mechanic actually uses prizes. Pass to the Critic.

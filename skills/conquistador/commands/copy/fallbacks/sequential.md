# Sequential fallback

Use for long-form copy when the host cannot run the writing and review roles as separate agents.
Keep the same method. Change only the machinery. Short-form copy never uses the roles; it follows the
[short-form mode](../ENTRY.md) in one pass.

## Draft

1. Anchor the audience, costly moment, awareness, outcome, mechanism, offer, proof, objection,
   action, surface, and language.
2. Select one proof, one mechanism, and the two or three benefits that matter most to this reader.
3. Write the promise and mechanism lines, then draft from the
   [sales argument](../references/sales-argument.md) and
   [headline patterns](../references/headline-formulas.md). Start the headline from the reader's
   want, pain, or identity.
4. Apply the writing roles as passes for the requested units: hook, body, CTA, and social proof;
   then variant when alternatives test different bets.

## Check

5. Run [copy review](../references/copy-review.md) on the finished draft. Remove unsupported claims;
   keep each fair inference that follows directly from the facts. Keep sourced specifics exact. Do
   not add disclaimers, hedges, or source text to the page; sources go in the operator note.
6. Apply voice, psychology, zero-risk, and critic as passes.
7. Rework the named weak unit instead of swapping one vague synonym for another.

Label this single-context. Do not call it independent corroboration. Do not invent quotes, metrics,
customers, or consent. Sending and publishing stay behind explicit human approval.

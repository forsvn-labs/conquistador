# Write a lead magnet page

Use when the copy offers a guide, template, checklist, calculator, or other resource in exchange for
an email address or another action. A lead magnet page is short-form: write it in your own judgment
from the user's facts, as the [copy entry](../ENTRY.md) says. This file adds no drafting rules.

The facts check covers the exchange too: remove any content the resource does not hold, any claim of
instant delivery when fulfillment is manual, and any saving or result the facts do not support. Keep
fair inferences from the contents. Add nothing to the copy. If the resource is not built yet, tell
the owner outside the copy.

Sending, collecting contacts, and publishing each need the owner's approval.

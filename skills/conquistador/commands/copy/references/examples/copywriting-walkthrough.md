# Copywriting example with synthetic data

This example is synthetic. It demonstrates local writing and review, not measured customer performance.

## Brief

A CSV comparison utility reports added, removed, and changed rows. The audience is an operations analyst who compares weekly exports. The requested deliverable is a headline, body block, and CTA. The provided specification supports local file comparison and CSV report export. No performance study or customer quote is supplied.

## Draft

Headline: Compare the rows in two weekly exports.

Body: Load the two CSV files to review added, removed, and changed rows. Export the comparison as a CSV report for your review process.

CTA: View the supported file format.

## Review record

The product specification supports the row comparison and report export. The draft makes no claim about time saved, revenue, or error elimination. The CTA requires a real format documentation destination; until supplied, its link remains a visible placeholder in the artifact.

## Revision example

An earlier line said the utility finds every reporting error. The critic returns REVISE because row differences do not establish which values are correct. The repaired copy describes comparison behavior and leaves correctness review with the analyst.

The final editorial PASS does not authorize publishing or prove that the copy converts. A future test needs its own audience, useful action, measurement plan, and approval.

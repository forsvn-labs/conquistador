# Write product-marketing copy

Produce the finished copy first. Use the customer's brand as the brand of record.

## Use this method

1. Draft from the craft. [Sales argument](references/sales-argument.md) covers promise, mechanism,
   offer, proof, objections, and argument order. [Headline patterns](references/headline-formulas.md)
   covers headlines and leads. [Examples](references/examples/direct-response-examples.md) shows
   strong and weak pairs.
2. Then check. [Copy review](references/copy-review.md) checks claims after the draft exists. Keep
   a sourced number exact, with its source beside it.

Keep the requested size and scope. For a small edit, return the edit and only the explanation it
needs. Read the [complete method](COMMAND.md) for routing, roles, and delivery. Sending and
publishing need the user's approval.

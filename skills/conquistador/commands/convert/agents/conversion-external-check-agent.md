# Conversion external evidence check

Review supplied outside-event evidence against the observed metric, population and timeline.
Preserve independence from the internal mapper where a separate context is available. Do not
assume an outside event explains a fixed share of problems or requires a mandatory live search.

Return `## External Factor Scan`, including Scan Parameters, Factor Assessment, External Factors
to Add to Tree, Ruled-Out Factors, and `## Change Log`. The legacy tree label means candidate map.

Factor Assessment retains Factor / Search Query / Finding / Status / Impact. Search Query records
a supplied query or a proposed query labeled not run. Include Source, evidence window and coverage
in Finding. Review competitor, market/seasonal, platform, policy, technology and macro conditions
for relevance, with other factors when the problem calls for them. Not applicable and missing
coverage are explicit; do not pad the scan or claim completeness from category count.

Keep Confirmed / Ruled Out / Possible status tokens. Confirmed means the external event itself
is evidenced; metric causation still needs hypothesis/verdict review. Possible includes untested
candidates, labeled evidence unavailable when applicable. Ruled Out requires evidence contradicting
the scoped candidate. No search results or absent source material do not rule out a cause.

For each relevant candidate identify exposed users, timing, plausible pathway, internal/external
interactions and deciding data. Impact remains unknown without evidence. A timeline mismatch can
weaken a candidate but delayed effects need consideration. Pass candidate ids and limits to the
hypothesis agent; do not recommend solutions or invent current platform/news facts.

Use supplied artifacts only within the current authorization. New collection or external changes
require their own scope; this method does not authorize or perform them. On revision preserve
unresolved coverage and add Feedback Response.

# Improve conversion performance

Improve the page, flow, or step the user asked about in your own judgment from the user's facts.
Load no other file for it. Then run only the facts check: remove claims the facts do not support,
keep fair inferences, and add nothing (no hedges, no source text, no disclaimers). Return only what
the user asked for.

A revised sales page or sales letter uses the `copy` command's long-form method instead.

Keep small edits small. Nothing is sent, published, spent, uploaded, or changed in an account
without the user's approval for that exact action. This approval governs actions; it adds nothing to
the deliverable.

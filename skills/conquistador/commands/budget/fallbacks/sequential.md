# Sequential allocation review

Use when the host cannot run the roles independently. Label the work single-context review.

1. Read [the allocation procedure](../references/marginal-return-model.md) and choose the evidence mode.
2. Draft amounts, alternatives, scenarios, and reserve with [allocator](../agents/allocator.md).
3. Recalculate totals and inspect constraints with [constraint checker](../agents/constraint-checker.md).
4. Review the recommendation with [critic](../agents/critic.md). Correct named defects and recheck dependent amounts.
5. Deliver using [format conventions](../references/format-conventions.md), including the decision, limits, next evidence, and human approval boundary.

Do not claim independent corroboration or execute spending. Missing data remains visible in the same contract used by the multi-agent path.

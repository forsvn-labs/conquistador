# Allocation example with synthetic inputs

This is a constructed local example, not an observed campaign. The budget is 1,000 units for a stated period. The user chooses a 300-unit reserve and a 600-unit concentration limit for any one test.

Test A has a supplied hypothetical placement quote of 400 units and a defined qualified-response observation. Test B is a proposed 300-unit learning experiment with an agreed observation window. Neither has measured incremental return.

The proposal allocates 400 to A, 300 to B, and 300 to reserve. The reconciliation is 400 + 300 + 300 = 1,000. Both test amounts fit the stated concentration limit. These are scenario constraints, not platform defaults.

Compare this with funding A only and holding 600 in reserve. The two-test proposal can answer more questions only if the team can measure and fulfill both. If B's destination is not ready, recommend A plus reserve and name the readiness check for reconsidering B.

Return stop conditions, owners, and the review date. Any later movement of the reserve requires the relevant approval. No result or return is claimed from this calculation.

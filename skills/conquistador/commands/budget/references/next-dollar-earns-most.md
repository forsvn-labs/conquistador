# Choose between allocation and learning

Use owned, comparable results when they can support the decision. Use [the marginal-return procedure](marginal-return-model.md) to separate historical average cost from incremental response.

When key response inputs are unavailable, define a learning question and a bounded test instead of pretending to optimize return. State what the test can reveal, how it will be observed, and how the result changes the next allocation.

Compare holding the reserve, continuing the current plan, and changing a bounded amount. Show expected consequences as scenarios with explicit assumptions. Rank the options by the actual objective, constraints, and uncertainty rather than a universal channel preference.

Return the recommended split, reason, alternative rejected, decision-sensitive unknown, and review trigger. If no candidate meets readiness or useful-observation requirements, recommend holding funds and identify the dependency to resolve. This remains a concrete allocation decision, not a request for every possible metric.

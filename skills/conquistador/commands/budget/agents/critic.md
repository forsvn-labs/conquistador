# Review the allocation recommendation

Receive the brief, allocation, evidence, constraint result, and scenarios. Apply [the review rubric](../references/rubric.md).

Check whether the recommendation follows from the objective and supplied evidence. Verify that unknown response is handled as uncertainty or a learning plan, and that a meaningful alternative was considered. Inspect the arithmetic and authority boundary.

Return PASS or REVISE with row, issue, consequence, and correction. Route allocation arithmetic and assumptions to the allocator, and constraint violations to the constraint checker. If no feasible proposal exists, an explicit hold/no-go recommendation can pass when its reasoning and next step are complete.

Do not substitute a numerical review score for missing evidence. Local review does not establish incremental return or live campaign performance.

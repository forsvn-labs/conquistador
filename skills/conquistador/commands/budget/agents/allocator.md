# Draft a bounded allocation

## Input contract

Receive the objective, budget, horizon, reserve policy, candidate channels, owned evidence, capacity, prohibited uses, and user constraints. Label each input observed, reported, assumed, or unknown.

## Procedure

Choose evidence-backed or learning-budget mode using [the marginal-return model](../references/marginal-return-model.md). Define comparable useful outcomes and avoid treating historical average cost as proven incremental response.

Draft an allocation and at least one feasible alternative. Show amounts, ranges, purpose, evidence, actual test floor, owner, and timing. State all scenario assumptions. Apply readiness checks before recommending a test.

Calculate allocated total plus reserve and reconcile it to the budget. Include downside/base/upside outcomes, delivery capacity, concentration, cash limits, and the cost of delay where relevant. No installed multiplier or platform spending floor supplies missing account evidence.

## Output contract

Return Mode and constraints, Evidence ledger, Allocation table, Alternatives and scenarios, Reserve reconciliation, Reallocation triggers, and Unresolved inputs. Recommend one option and explain its tradeoff. Keep live changes behind explicit approval.

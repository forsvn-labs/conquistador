# Inspect Bing visibility without assuming another product's backend

Use this check when Bing is an actual target or a task has current evidence that Bing retrieval matters to the selected product. Do not require Bing indexing as a universal prerequisite for every AI-answer service.

## Inspect the requested URL

Record the URL, intended audience, response status, access restrictions, canonical target, and available index evidence. Use authorized Bing Webmaster Tools access or other current task evidence when available. If access is unavailable, return the exact check needed; do not claim a site is verified or indexed.

Separate crawl access, submission, index inclusion, ranking, and citation. Evidence for one state does not establish the others. Bing query measurements describe that source and scope; they are not a measured proxy for another answer product's visibility.

## Verify the target product

For an AI-answer task, identify the actual product, retrieval mode, question, date, and visible result or current official documentation. Do not infer a fixed backend map from the product name. A model response without retrieval provides no observation about current index availability.

Record observed citations and URLs separately from mentions, clicks, and conversions. Use [citation readiness](../geo-citation-readiness-checklist.md) for content checks and preserve unavailable retrieval evidence as unknown.

## Submission handoff

A sitemap, URL submission, or IndexNow notification can be proposed when the relevant documented interface supports the intended action. Inspect current requirements and confirm host support, destination, and authority before execution. A submitted notification is not proof of instant indexing or citation.

Return the proposed action with exact URLs, reason, missing access, and expected receipt. Do not submit or publish merely because the audit is complete. Host-confirmed execution must remain distinct from the resulting indexing or retrieval observations.

## Deliver

Report the inspected states, evidence, unresolved condition, and smallest useful next check. Recommend a correction when a verified access or consistency problem exists. Keep ranking and citation outcomes unclaimed until observed in the requested scope.

# Check target consistency

## Input and procedure

Receive the targets, baselines, stage definitions, initiative mapping, and evidence. Recalculate the arithmetic with compatible units, cohorts, and periods. Identify double-counted effects, impossible populations, pending outcomes, and missing costs.

Compare the proposed result with the no-change scenario. If the target merely follows existing movement, explain that limitation; do not add an arbitrary stretch percentage. If the proposed improvement exceeds available evidence, flag the assumption and request a sensitivity case.

Check whether the responsible team has the capacity and authority to perform the proposed work. Distinguish a missing business decision from a calculation error. A target's desirability does not establish feasibility.

Return Findings with location, observed defect, consequence, correction, and unresolved evidence. Use PASS when no material consistency defect remains, REVISE for correctable defects, or NEEDS_CONTEXT for required missing evidence. No verdict establishes live performance or spending authority.

## Review boundary

Preserve the supplied evidence and mark assumptions explicitly. If feedback changes a definition, recheck affected calculations and dependent targets. Local review is not a live measurement.

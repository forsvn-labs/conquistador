# Voice auditor

Edit the format-checked ads so they read as the brand and the reader would speak. Use the supplied
brand voice or past ads; if there are none, use plain, direct sentences.

Cut vague praise, unsupported superlatives, jargon, repeated sentences, disclaimers in the drafting
voice, and any line a competitor could run unchanged. Keep each variation's angle, opening, offer
terms, quotes, prices, and URL. If an edit changes a claim or a length, send that variation back
through the format check. Return the edited set with a one-line reason for each material edit, then
pass it to the critic.

# Format checker

Check the finished ads against the selected network and placement. Use the dated platform facts
in the [craft reference](../references/ad-craft.md), the platform pack, any limit in the user's
brief, and [format spec](../references/format-spec.md).

Count characters; do not estimate. For each component record its length, the limit, and pass or
fail. Check that each responsive search asset reads alone and repeats no other, that offer terms
and the call to action match the destination, and that videos have captions and a still fallback.

Return the exact field and a shorter version for each failure. Mark a platform fact that may have
changed since its date as "confirm before launch"; it does not block the draft. Pass the set to
the voice auditor. A format pass is not platform approval.

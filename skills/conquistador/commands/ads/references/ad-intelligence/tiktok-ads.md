# Plan a TikTok Ads video test

This is a campaign decision procedure. It supplies no performance benchmark or
claim of current platform verification. Record the source, date, placement, region,
and account scope of platform constraints before using them. If verification is
unavailable, deliver a draft with the affected setup decisions unresolved.

## Select an authorized asset

Record spark_mode as Spark or in-feed and identify the post or video to use.
Spark Ads require the applicable creator/post authorization. Check usage rights,
sponsorship disclosure, audio rights, region, placement, and current account rules.
Do not assume a creator format is more trusted or an in-feed asset scales better.

## Design a viewable message

Specify the opening visual, spoken words, on-screen text, product demonstration,
and destination action. Each must convey an accurate offer. Use captions and a
still or poster fallback so essential proof and terms remain accessible. Evaluate
both audio and silent presentation; do not presume one is always the viewing mode.

For each variant, choose one changed component and a falsifiable question. For
example, compare a demonstrated task with a spoken task description while retaining
the same offer, actor, duration, and destination. If multiple elements must change,
label the comparison a concept test and limit causal conclusions accordingly.

## Define evaluation before production

Record the outcome event, attribution window, loss ceiling, observation requirement,
and production capacity. View metrics can help locate abandonment within a video,
but no opening duration or hold rate predicts a profitable winner by default.
Preserve the exact duration and denominator of each exported view metric.

Plan refresh review using event maturity and account results. Neither rapid fatigue
nor the superiority of a particular visual style is assumed. A video that cannot
show the required proof needs a different brief; a missing consenting narrator can
be resolved by another truthful format, not a fabricated testimonial.

Return finished ad text, shot and audio notes, authorization gaps, destination
checks, controlled variants, and a measurement contract. TikTok Shop or search
placements require a separately verified specification before inclusion.

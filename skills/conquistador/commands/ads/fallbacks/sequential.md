# Sequential paid campaign procedure

Run the same roles in order when the host has no independent agents. Do not claim
independent review contexts. A fast request can shorten commentary, not omit gates.

1. Read supplied product, audience, offer, brand, destination, proof, and account
   evidence. Use references/research-workflow.md. Ask only for missing information
   that changes the feasible test. Missing platform verification permits a labeled
   draft, not a claim of launch readiness.
2. Run agents/strategist.md with the matching ad-intelligence pack. Record one
   network and audience scope, event choice, controlled variant plan, attribution
   limits, loss ceiling, and evidence requirement. Use creative-cadence.md when
   production or budget matters.
3. Run agents/composer.md for hero, variant_a, and variant_b. Apply
   message-transmutation.md and format-spec.md to the chosen components.
4. Run agents/format-checker.md. On REVISION_REQUIRED, repair and recheck. A second
   failed pass is FORMAT_FAIL and blocks launch readiness.
5. Run agents/voice-auditor.md, rechecking any changed format or claim.
6. Run agents/critic.md and references/rubric.md. On FAIL, repeat composer through
   critic with precise feedback, at most two revision cycles. Preserve unresolved
   blockers with the best draft; do not silently convert them to approval.
7. If optional polish ran, compare protected_tokens, claims, terms, and URLs for
   each edited variant. Preserve the approved predecessor and flag regressions.
8. Deliver the three artifacts in format-conventions.md with one human review
   boundary. Launching, spending, audience uploads, and account changes each require
   explicit authority for the exact action.

If called by `campaign`, retain its offer, eligibility, budget authority, and
campaign ID as inputs. Return scoped artifacts and test limits to the caller.
Actual post-launch performance belongs to `results`. Planned figures
must not enter that handoff as observed results.

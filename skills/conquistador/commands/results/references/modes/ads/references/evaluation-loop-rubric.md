# Review the full evaluation cycle

Apply this frame after the paid-specific rubric. Confirm that the input hypothesis,
actual evidence, recommendation, and durable record describe the same scope.

Check that the evaluator:

1. Uses supplied actual measurements and labels plans, estimates, and missing data.
2. Preserves source definitions, denominators, windows, cohort maturity, and limits.
3. States observations before interpretations and distinguishes alternatives.
4. Applies the declared decision rule, including acceptable loss and uncertainty.
5. Returns one bounded next action without granting external authority.
6. Records unfavorable and inconclusive outcomes as well as favorable ones.
7. Promotes only evidence-backed, scoped learning with an expiry condition.

Use the seven paid rubric dimensions and existing /70 score interface; do not add
a competing score gate. A missing loop store does not block an otherwise valid
standalone evaluation. Return the artifact and row inline when persistence is
unavailable. Missing actual evidence blocks a performance verdict and produces a
measurement plan. A review score is not evidence of business success.

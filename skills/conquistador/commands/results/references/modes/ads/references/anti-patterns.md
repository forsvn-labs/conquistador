# Paid evaluation failure checks

| Defect | Required correction |
|---|---|
| A plan is called a result | Require actual delivery or outcome evidence; otherwise return a measurement plan |
| Missing means zero | Restore missing values and block affected calculations |
| Blended audiences become a cell | Separate compatible scopes or block cell-specific claims |
| Rate without denominator | Supply actual counts and event definitions |
| Immature cohort loses to mature cohort | Align event lag and follow-up or mark provisional |
| Private threshold decides confidence | Use the predeclared information requirement and sensitivity |
| Correlation becomes fatigue proof | Name competing causes and evidence needed to distinguish them |
| View rate predicts sales | Keep attention diagnostic and inspect qualified outcomes |
| Low retargeting CPA justifies more spend | Inspect overlap and incremental evidence, then propose a bounded test |
| A favorable score grants action | Separate quality review from human spend/account authority |
| Several variables change under a causal claim | Describe a concept comparison or isolate a follow-up test |
| Weak cycle disappears from the ledger | Record the truthful outcome with caveats and provenance |
| One cycle becomes a universal rule | Restrict learning to its evidence, scope, uncertainty, and expiry |

A spending limit protects the account; a statistical evidence requirement answers
a performance question. Keep both visible. Do not replace either with a fixed
platform benchmark or invent a certainty label from elapsed time.

# Captions and next actions

Write text that helps the viewer understand the asset and complete the intended next step. Use the matching local platform pack for channel decisions. Resolve current field limits and account capabilities in the task record; this reference contains no universal character, hashtag or timing defaults.

## Caption procedure

1. Record the selected account, format, field limit and source/date of verification. If the limit is unknown, mark the draft pending a format check.
2. Write the task or useful result first. Add only the context needed to interpret the asset, including material conditions and disclosures.
3. Preview the collapsed caption in the intended client. Record the actual visible text and whether the reader has enough information to choose to expand it.
4. Check the caption against spoken and visible claims. Add a transcript or captions as needed for accessibility; do not conceal a disclosure behind optional expansion.
5. Add a hashtag only when it names a relevant topic, context or required campaign identifier. Record why it helps; do not target a fixed count or promise a ranking effect.

## Platform-specific checks

| Destination | Check before approving the text |
| --- | --- |
| TikTok | Verify caption and account link capability; inspect the action path in the viewing interface. |
| Instagram Reels | Check cover, collapsed caption and profile destination; verify collaborator and music permissions. |
| YouTube Shorts | Write title and description as distinct fields; check any related-video path for the account. |
| X | Check the account entitlement, media preview and thread order; keep the first post understandable alone. |
| LinkedIn | Preview collapsed text and attached document/video; verify that the professional task and access terms remain clear. |

## Next-action decision

Choose an action that follows from the value delivered. A reference can invite a save; a demonstration can link to a task; a discussion can ask a specific question. These are choices to justify, not platform performance rankings.

Specify exact copy, destination, position in the asset, access terms and all steps required after viewing. Verify whether a link, profile route, player control or comment route is actually available. Do not require link-in-comment placement based on an assumed reach penalty.

For a cross-platform variant, review the entire action path. Retain a working choice when it still fits; change it when the interface, account capability or audience task requires a different path.

## Production check

Place every overlay with exact text, timing, position and style. Test reading at the intended display size, with interface overlays and motion. Use the supplied brand treatment and enough contrast. A sound-off viewer must receive essential claims and conditions. Give the producer the text files, placement table, caption file and unresolved checks.

## Failure conditions

Block a misleading claim, inaccessible essential information, unsupported destination or missing permission. Return an incomplete format check as pending. Do not invent evidence that a common CTA, audio track or hashtag arrangement performs better.

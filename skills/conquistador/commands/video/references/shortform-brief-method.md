# Short-form brief method

Turn a supported campaign angle into an executable production brief and a bounded learning plan. The user chooses an outcome; the skill resolves the primary platform, assets, production mode and next action from the available context.

## Resolve the job

Use the skill front door and sequential fallback to collect the required context. Read the product facts, audience needs, permitted customer language and relevant account evidence. Missing customer quotes do not justify invented voice-of-customer text. Record a cold-start assumption when the user supplies only an audience description.

Choose one primary brief and the requested platform variants within the agreed resource scope. Each variant needs a complete destination assessment, not forced changes to every element. A single-platform request does not require variants.

## Produce the brief

1. The format agent identifies the actual destination requirements and pending checks. A method date is not platform verification.
2. The voice-of-customer and production-mode work identifies usable language, evidence, assets and production constraints.
3. The hook agent proposes openings based on the task and available payoff. Catalog membership and a fixed timing window are not quality requirements.
4. The storyboard specifies every shot's timing, framing, visible action, exact text and audio cue. Use a read-through or preview to choose duration.
5. The audio agent specifies a rights-cleared track, recordable voice-over direction or deliberate silence. The caption agent supplies accurate text and a checked action path.
6. For each variant, reassess the opening, timing, audio, text and destination. Record what changes and what remains valid, with reasons.
7. The critic reviews hook, production, destination fit and brand fit. Retain the legacy `algorithm-fit` identifier for destination and measurement-plan review only.
8. Apply the existing language polish after substantive review, then verify that claims and conditions survived the edits.

Use the agent sequence in `../fallbacks/sequential.md` for a host without subagents. The same artifact requirements apply.

## Review and handoff

Use `format-conventions.md` for the complete artifact fields and body sections. Include the source and permission for actual quotes; proposed copy is not a testimonial. Provide exact asset paths, timing, text, rights, preview results, owner and unresolved checks. For rendered work, carry the still or poster and accessible output requirements from the production contract.

Use `success-criteria-templates.md` to define account-local measurements, a baseline or baseline-collection plan, resource limits and interpretation limits. A draft pass does not prove a performance result. Use `evaluate-shortform` when actual artifacts and measurements are available.

Allow at most two critic rewrite cycles. A standing failure remains visible with an internal `done_with_concerns` grade and requires an operator decision. Publishing, sending or spending requires separate exact authorization.

## Boundaries

Use `brief-creative` for a static visual brief, `create-paid-campaign` for paid-ad policy and offer review, and `plan-campaign` for channel allocation. Research supplied to this skill may suggest a test; it does not authorize borrowing a practitioner's expression, manufacturing evidence or treating another account's results as a default.

The method preserves truthful UGC, asset rights, production specificity and a complete human handoff. It does not depend on an external person's framework or an alleged platform performance formula.

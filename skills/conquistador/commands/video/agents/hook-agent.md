# Hook agent

Write an opening that identifies a useful task and makes a promise the artifact can fulfill. Read `references/hook-archetypes.md` and the selected local platform pack. Use user-provided language only with its actual source; do not manufacture a customer quote.

## Inputs

Use the angle, primary platform, market, brand mode, production mode, format specification, authorized claims, audience context and available assets. Research examples can suggest a test; their popularity does not make an opening mandatory.

## Procedure

1. Identify the viewer's immediate question or decision.
2. Select a visible task, decision comparison, bounded result or complete-answer opening according to the available evidence.
3. Write the recommended opening and two meaningful alternatives. Each must change an entry decision the producer can compare.
4. Specify exact first frame, action, spoken line if any, overlay, audio state and timing. Match timing to comprehension and the format specification.
5. Map the opening promise to its supporting shot or source. Check consistency among text, image and speech and check accessibility in the intended playback conditions.
6. Explain the recommendation and the evidence that would cause a different choice.

## Output

Return Recommended, Alternative A and Alternative B blocks. Each includes the production specification, the intended viewer, the promise, the payoff location and any unverified assumption. If an element is intentionally absent, explain how the information remains understandable.

Return a Hook Reasoning paragraph and a Change Log. Tag an opening descriptively if helpful; a name, performance tier or copied timing formula is not an acceptance requirement. Do not force all three elements to appear simultaneously when that makes reading or listening harder.

## Acceptance

Reject placeholders, unsupported numbers, contradictory messages, inaccessible essential information and an opening whose answer never arrives. Return an unresolved claim to the evidence owner. Do not claim that a phrase, timing window or archetype causes distribution without a suitable measured comparison.

# Review an artifact against its contract

Use this compact review when a bounded artifact can be assessed from the supplied brief and evidence. For a full evaluation, use the skill's [critic contract](../agents/critic-agent.md). The compact review does not replace a required specialist or human approval.

## Establish the expected result

Identify the requested artifact, intended user, constraints, and acceptance evidence. Inspect the actual artifact at the requested scope. If rendering, execution, or source material is unavailable, state that limitation before issuing a verdict.

## Record material defects

For each defect, name its location, expected behavior or content, observed mismatch, evidence, and consequence. Separate a demonstrable error from a preference or untested concern. A missing requirement must not disappear into an average score.

Check factual claims against supplied sources and check outputs against the brief's protected terms. Confirm that the next person can use the artifact without hidden dependencies. Identify external actions or decisions that still require authority.

## Return the review

Return PASS when the inspected artifact meets the applicable contract with no material unresolved defect. Return REVISE when a local correction is possible, naming the correction and affected unit. Return BLOCK when missing access, evidence, or authority prevents the required evaluation or action.

For revisions, recheck the changed unit and any dependent claims or behavior. Explain residual uncertainty rather than claiming a deterministic quality judgment. Editorial or structural review alone does not prove audience response or business performance.

## Example, synthetic

An artifact links to a required resource that is absent from its installed package. Record the link, missing target, and affected task. Request a contained resource or an explicit handoff, then verify the repaired path. A well-written description does not make the original artifact usable.

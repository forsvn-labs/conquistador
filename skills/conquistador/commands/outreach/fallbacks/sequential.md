# Portable sequential fallback

Use this procedure when separate specialist agents are unavailable. Keep distinct notes per pass;
one agent can execute the full method without private tools or external services.

1. Establish requested scope, commercial or research intent, sender affiliation, channel, and action boundary.
2. Run [signal analysis](../agents/signal-analyst.md); record the supplied sources and rank the signal.
3. Run [strategy](../agents/strategist.md): pick the situation, structure, lead fact, and ask from
   [the craft reference](../references/frameworks/cold-email-frameworks.md).
4. Run [composition](../agents/composer.md) with the selected mode and channel.
5. Check the draft: [claim review](../agents/proof-selector.md) and the signal check under
   [the method](../references/method.md).
6. Run [voice review](../agents/voice-auditor.md), then [critique](../agents/critic.md).
7. Revise failed points at most twice. Preserve any unresolved FAIL and its reason.
8. Recheck final claims and commitments against sources; return [the artifacts](../references/format-conventions.md).

For replies, start with [classification](../agents/reply-classifier.md) and
[reply composition](../agents/reply-composer.md), then the same checks, voice, critique, and final review.
For a campaign caller, honor supplied scope and stricter selection thresholds without inventing
missing evidence. Never turn a generic template into targeted readiness because its craft score passed.
No-pitch research with no signal returns NEEDS_SIGNAL. One requested message stays one message.
Draft approval is separate from exact action approval; this fallback performs no external action.

# Write outreach people answer

Lead with the strongest true fact, ask once, and keep the recipient in control.

## Use this method

Draft from the [craft reference](references/frameworks/cold-email-frameworks.md) first, and compare
the draft with the annotated [sales](references/examples/pairs-sales.md) and
[relationship](references/examples/pairs-relationships.md) pairs. Then run [the check](references/method.md)
on the finished draft. Keep the requested output size and scope. For a small edit, return the edit
and only the explanation it needs.

Read the [complete method](COMMAND.md) when its detailed procedure is needed.
Expand linked playbooks only when their condition or stage applies.
The Core list is a reference collection, not an instruction to load every file.

# Social copy examples

All products, briefs, copy and reviewer judgments below are synthetic teaching examples. They
are not customer evidence, audience tests, verified platform rules or publication-ready claims.
Use only facts supported by the real task when adapting them. Limits and previews remain pending.

## Video caption: import troubleshooting

Brief: explain how to recover rejected rows; goal save; company voice. The fictional product
has a rejected-row log. Confirm that capability before adapting this copy.

- Variant A: "Find the rejected row before you retry the import."
- Variant B: "Retry everything or fix one row? Start with the error log."
- Body: "Open the rejected-row log. Check the missing field. Correct that row, then retry the
  rejected rows. Keep the original file so you can compare the result."
- CTA: "Save these steps for the next failed import."
- Format spec: caption plus screen recording of the error, correction and retry. Production
  owner must supply the screen capture, captions, accessible text and account format constraints.
- Method: task opening versus decision opening, same answer and CTA. Observe saves only if
  available with a defined denominator/window. A save does not prove a successful import.

Weak version: "Importing just got easier. Learn more!" It omits the steps and destination.
The strong version delivers a bounded answer; the weak version fails promise delivery and CTA
clarity. Neither version gets a format-compliance pass until task-local checks are complete.

## Short title and description: a documented configuration change

Brief: describe a fictional settings comparison; goal click. No measured speed improvement exists.

- Variant A: "Compare the default export with the compact export."
- Variant B: "Need a smaller export? Check which fields you can omit."
- Body: "List the fields your receiver needs. Keep those fields in both exports. Compare file
  size and check that the receiving system accepts each file."
- CTA: "Read the field checklist at the supplied documentation destination."
- Production: title, description, example files, screen sequence and destination owner. Count
  each copy field separately; current field limits and preview are unknown.

Weak version: "Make exports ten times faster with one secret setting." It invents a result
and withholds the setting. Flag evidence and promise delivery; do not reward the dramatic opening.

## Single text post or thread: reviewer handoff

Brief: a fictional team needs clear ownership; goal engagement; founder voice without invented
personal history.

- Variant A: "A review request needs a decision owner and a deadline."
- Variant B: "Who can accept this draft? Put that name in the review request."
- Body: "Include the draft, the decision needed, the owner and the response deadline. If the
  owner cannot respond, name the escalation path before the deadline passes."
- CTA: "Which decision is hardest to assign in your review process?"
- Format: choose a single post if the complete answer fits supplied constraints. If a thread is
  requested, make the first item useful and specify every item. Do not claim either format converts better.

Weak version: "Review is broken. Agree?" It gives no repair and requests a token response.

## Carousel or text post: choosing a reporting window

Brief: explain comparable measurement; goal save; company voice.

- Variant A: "Compare campaign results over the same observation window."
- Variant B: "A day-one result and a day-seven result answer different questions."
- Body: "Choose the decision first. Use matching metric definitions and windows. Show missing
  values. Keep paid and organic observations separate unless the decision explicitly combines them."
- CTA: "Keep this checklist with your next readout."
- Carousel production: opening slide, definition slide, comparison example, limitations slide,
  final checklist. Supply captions, accessible text, asset owner and a preview check. A text
  alternative can carry the same complete answer if production capacity is unavailable.

Weak version: "Our highest-performing framework guarantees growth." No evidence supports the
performance or guarantee. Do not replace that gap with person authority or pack citations.

## Review and handoff for every example

Use the five dimensions in rubric.md. Cite actual passages; mark format or destination checks
pending. Include Hook variants, Body, CTA, Format spec, Legibility, Why this works, Critic verdict
and Anti-patterns triggered. A loaded draft pack uses Packed, `pack_verified: none` and its actual
method_updated date. Product context is synthetic here; a real task uses supplied sources or Absent.
Keep native copy separate from internal checks. Preserve local artifact path and optional terminal
polish handoff. Do not send, schedule or publish examples, and do not write synthetic observations
into performance stores or pack changelogs.

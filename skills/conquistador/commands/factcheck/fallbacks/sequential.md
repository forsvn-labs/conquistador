# Sequential fallback — knowledge review

Use when the host cannot run assessor, contradiction checker, resolver, and an independent verifier
as separate contexts. Keep the same method; change only the machinery. Label the result
**single-context review**, never independent corroboration.

## Order of work

1. **Fix the claims.** State exactly what will be published or decided; split compound claims.
   Enumerate all sources in use, cited or not, per the
   [knowledge review method](../references/knowledge-review-method.md).
2. **Assess sources.** One pass per source recording authority, freshness date, staleness category,
   uncertainty, and provenance route ([review evidence scope](../references/provenance.md)). Mark
   repetition — repeated claims count once.
3. **Build the matrix and classify conflicts** with the
   [contradiction protocol](../references/contradiction-protocol.md): data, causal, scope,
   freshness.
4. **Resolve by weighing**, writing one sentence per loser on why it lost. Attach real dissent
   instead of erasing it; label contested items unresolved rather than forcing a winner.
5. **Counter-read pass.** Re-read as a hostile skeptic: construct the strongest evidence-led case
   against each resolution, state what survives. This is a fallback check inside one context —
   record that no independent route ran.
6. **Rubric and recheck.** Grade against the [review rubric](../references/review-rubric.md);
   enforce the H-KNOW obligations: no fabricated sources, contradictions surfaced, dated or
   event-based recheck triggers set for every surviving unknown.

## Stops

- **Missing input:** a load-bearing source cannot be obtained → record it as missing data in the
  matrix and mark the affected claim's confidence downgraded; never substitute an assumption.
- **Factual uncertainty:** a claim cannot be traced to any source at all → label it unsupported;
  the review does not manufacture provenance.
- **Credential stop:** a source requires access you do not have (paywalled, private, deleted) →
  name the gap; do not paraphrase from memory and present it as the source.
- **External action:** the resolution informs decisions only; publishing, sending, spending, and
  releasing are never authorized by this skill.
- **Critic failure:** the counter-read cannot break the resolution but material doubts remain →
  ship them listed as dissent, not silently dropped.
- **Human verdict:** every review ends at a human decision about the claim; this skill never
  approves publication, action, or release.

# Specialist roster

The Conquistador parent uses these roles for assignments that cross GTM capabilities. Each role
combines existing outcome skills, project knowledge, and named composition workflows. These roles do
not replace the 38 outcomes or create another method library.

| Specialist | Use for | Primary skills | Named workflows |
| --- | --- | --- | --- |
| [Ads](ads-agent.md) | Paid campaign creation and account-ready changes | `create-paid-campaign`, `evaluate-paid-campaign`, `allocate-marketing-budget` | `paid-campaign-loop` |
| [Copy](copy-agent.md) | Routing and writing the correct copy form | `write-copy` plus the channel owner | `position-to-campaign`, `create-landing-page`, `outreach-sequence` |
| [Direct-response landing](dr-landing-agent.md) | Offer-led pages with a complete belief and action path | `research-positioning`, `write-copy`, `brief-creative`, `improve-conversion` | `create-landing-page` |
| [SaaS landing](saas-landing-agent.md) | Product-led pages for trial, demo, or qualified activation | `research-positioning`, `write-copy`, `brief-creative`, `improve-conversion` | `create-landing-page` |
| [Data diagnosis](data-diagnosis-agent.md) | Find the first measured break and competing explanations | `diagnose-growth`, `measure-growth`, `model-growth-funnel` | `target-to-growth-plan`, `content-performance-review` |
| [Campaign data](campaign-data-agent.md) | Event contracts, extracts, holdouts, and money-event readouts | `measure-growth`, `evaluate-paid-campaign`, `evaluate-outreach` | `paid-campaign-loop`, `measured-initiative-loop` |
| [Creative assets](creative-assets-agent.md) | Produce and review a coherent volume of paid or short-form assets | `brief-creative`, `create-paid-campaign`, `create-shortform` | `paid-campaign-loop`, `shortform-campaign`, `creative-asset-review` |

Use [specialist team execution](../orchestration/specialist-team.md) for assignment packets,
dependencies, parallel work, integration, and fallback. Use
[connect accounts](../methods/connect-accounts.md) and [stack setup](../methods/stack-setup.md)
when a role needs a missing data or provider interface.

The parent may use one role or several. Do not add a coordinator specialist. The parent coordinates.
Do not add a reviewer specialist when an existing review outcome supplies the judgment.

# chat.read

Read team chat channels, threads, and messages.

## Answers

- What did the team decide about a launch, a price, or a message?
- What do community members ask in shared channels?

## Find the tool

Search phrases: `search messages`, `channel history`, `list channels`.

## Providers

| Provider | Search for | Needs |
| --- | --- | --- |
| Slack | `search messages`, `conversations history` | Channel ID or query; a user token for search |
| Discord | `channel messages` | Channel ID |
| Microsoft Teams | `channel messages list` | Team and channel ID |

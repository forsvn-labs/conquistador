# analytics.read

Read web and marketing analytics: traffic, sources, campaigns, conversions, and landing pages.

## Answers

- Which channels and campaigns bring visitors, and which of them convert?
- Which landing pages gain or lose traffic over a period?
- What changed in the funnel before and after a launch?

## Find the tool

Search phrases: `run analytics report`, `website traffic sessions by source`, `conversion events report`.

Ask for the smallest date range and the fewest dimensions that answer the question.

## Providers

| Provider | Search for | Needs |
| --- | --- | --- |
| Google Analytics 4 | `runReport` in the Analytics Data API | Property ID (`properties/123456`), date range, dimensions, metrics |
| Plausible | `stats query` or `aggregate` | Site domain, period, metrics |
| PostHog (web) | `web analytics` or `query` | Project ID; HogQL for custom reports |
| Mixpanel | `segmentation` or `insights` | Project ID, event name, date range |
| Amplitude | `event segmentation` | Event name, start and end date |
| Vercel Web Analytics | `web analytics` | Project ID |

# seo.read

Read search performance: queries, rankings, impressions, backlinks, and keyword data.

## Answers

- Which queries and pages gain or lose clicks?
- Which keywords have demand that no page serves yet?
- How does the site compare to competitors on links and rankings?

## Find the tool

Search phrases: `search analytics query performance`, `keyword rankings`, `backlinks domain overview`.

## Providers

| Provider | Search for | Needs |
| --- | --- | --- |
| Google Search Console | `searchanalytics query` | Site URL (`sc-domain:example.com`), date range, dimensions |
| Bing Webmaster Tools | `query stats`, `page stats` | Site URL |
| Ahrefs | `site-explorer` (organic keywords, backlinks), `keywords-explorer` | Target domain, country |
| Semrush | `domain organic`, `phrase this` | Domain or phrase, database (country) |
| Moz, SE Ranking | `url metrics`, `keyword research` | Domain or keyword |

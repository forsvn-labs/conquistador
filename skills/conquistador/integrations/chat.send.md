# chat.send

Post a message to a team chat channel or thread.

This is a send. Show the channel and the exact text, then get the user's explicit approval.

## Find the tool

Search phrases: `post message to channel`, `send chat message`, `reply in thread`.

## Providers

| Provider | Search for | Needs |
| --- | --- | --- |
| Slack | `chat postMessage` | Channel ID; `thread_ts` for a reply |
| Discord | `channel messages create` | Channel ID |
| Microsoft Teams | `channel messages send` | Team and channel ID |

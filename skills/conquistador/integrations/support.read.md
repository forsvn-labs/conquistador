# support.read

Read support tickets, conversations, and customer feedback.

## Answers

- What do customers ask, complain about, and praise, in their own words?
- Which issues block activation or cause churn?

## Find the tool

Search phrases: `list support tickets`, `search conversations`, `customer feedback`.

Quote customers only with permission. Summarize themes and counts.

## Providers

| Provider | Search for | Needs |
| --- | --- | --- |
| Intercom | `conversations search` | Query and date filter |
| Zendesk | `search` (tickets), `tickets list` | Query |
| Help Scout | `conversations list` | Mailbox ID |
| Plain, Front | `threads`, `conversations search` | Query |
| Canny, Productboard | `posts list`, `notes list` | Board ID |

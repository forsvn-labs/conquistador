# search.read

Search the web and read pages for research, competitors, and fact checks.

## Answers

- What do competitors claim, charge, and show on their pages today?
- Which sources support or contradict a claim?
- What do people ask about this category?

## Find the tool

Search phrases: `web search`, `search the web for pages`, `fetch web page content`.

Cite the URL and the access date for every fact you use.

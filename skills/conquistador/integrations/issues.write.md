# issues.write

Create or update issues, comments, and project items.

This is a write. Show the tracker, the team or repository, and the exact title and body. Get the
user's explicit approval for each call.

## Find the tool

Search phrases: `create issue`, `update issue`, `add comment to issue`.

## Providers

| Provider | Search for | Needs |
| --- | --- | --- |
| Linear | `issueCreate`, `commentCreate` | Team ID |
| GitHub | `issues create`, `issues comments create` | Owner and repo |
| Jira | `issue create` | Project key, issue type |
| Asana, ClickUp | `tasks create` | Project or list ID |

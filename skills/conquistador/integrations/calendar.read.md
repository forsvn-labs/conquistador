# calendar.read

Read calendar events and availability.

## Answers

- Which dates are free for a launch, a webinar, or an event?
- Which conflicts affect a campaign timeline?

## Find the tool

Search phrases: `list calendar events`, `free busy availability`, `get event`.

## Providers

| Provider | Search for | Needs |
| --- | --- | --- |
| Google Calendar | `events list`, `freebusy query` | Calendar ID, time window |
| Microsoft Outlook | `calendar view`, `get schedule` | Time window |
| Cal.com, Calendly | `bookings list`, `scheduled events` | User or event type |

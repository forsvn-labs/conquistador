# email.send

Send or schedule an email, broadcast, or sequence step.

This is a send. Show the sender, recipients or segment, subject, body, and send time. Get the
user's explicit approval for each send. Send a test to the user first when the provider allows
it. Run `conquistador check` on the copy before you ask.

## Find the tool

Search phrases: `send email`, `send broadcast campaign`, `schedule email`.

## Providers

| Provider | Search for | Needs |
| --- | --- | --- |
| Gmail | `drafts create` (prefer), `messages send` | Raw MIME or structured message |
| Resend | `emails send`, `broadcasts create` | Verified sender domain |
| Customer.io | `send transactional`, `broadcasts trigger` | Template or broadcast ID |
| Mailchimp | `campaigns create`, `campaigns send` | Audience ID; a test send first |
| Loops | `transactional send` | Transactional ID |

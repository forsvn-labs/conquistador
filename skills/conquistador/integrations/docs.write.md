# docs.write

Create or update documents, pages, and files.

This is a write. Show the destination and the content, then get the user's explicit approval.
Prefer a new page or a draft over an edit to an existing page.

## Find the tool

Search phrases: `create document page`, `update page content`, `upload file`.

## Providers

| Provider | Search for | Needs |
| --- | --- | --- |
| Notion | `pages create`, `blocks children append` | Parent page or database ID |
| Google Drive | `files create` (with conversion to Docs) | Folder ID, MIME type |
| Confluence | `pages create` | Space key, parent page ID |
| GitHub | `repos contents create or update` | Owner, repo, path, branch |

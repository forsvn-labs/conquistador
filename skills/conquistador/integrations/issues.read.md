# issues.read

Read issues, projects, cycles, and roadmaps from the issue tracker.

## Answers

- What ships next, and which launch dates depend on it?
- Which requests and bugs repeat?

## Find the tool

Search phrases: `list issues`, `search issues`, `get project`.

## Providers

| Provider | Search for | Needs |
| --- | --- | --- |
| Linear | `issues` (GraphQL), `projects` | Team key or filter |
| GitHub | `issues list`, `search issues` | Owner and repo, or a search query |
| Jira | `search` (JQL) | JQL with a project key |
| Asana, ClickUp | `tasks list` | Project ID |

# social.read

Read social posts, profiles, comments, mentions, and post metrics.

## Answers

- Which posts, formats, and hooks earn reach and replies?
- What do people say about the product or the category?
- What does a creator or competitor post, and how often?

## Find the tool

Search phrases: `list social posts`, `post engagement metrics`, `search posts mentions`.

## Providers

| Provider | Search for | Needs |
| --- | --- | --- |
| X | `users tweets`, `tweets search recent` | User ID or query; API tier limits apply |
| LinkedIn | `posts`, `organization share statistics` | Organization or member URN |
| Buffer | `updates sent`, `analytics` | Profile ID |
| YouTube | `search list`, `videos list` with `statistics` | Channel ID or query |
| Instagram, Facebook | `media insights`, `page posts` | Business account or page ID |
| TikTok | `video list`, `video query` | Business account |
| Reddit | `search`, `subreddit new` | Subreddit or query |

# product-analytics.read

Read product usage: events, funnels, retention, cohorts, and feature adoption.

## Answers

- Where do new users drop out between signup and first value?
- Which features do retained users adopt in their first week?
- Did an experiment change activation or retention?

## Find the tool

Search phrases: `query product events`, `funnel conversion retention cohort`, `insights trends query`.

Name the event and the date range. Ask for aggregates, not raw user rows.

## Providers

| Provider | Search for | Needs |
| --- | --- | --- |
| PostHog | `query` (HogQL), `insights`, `funnels` | Project ID, event names |
| Mixpanel | `funnels`, `retention`, `segmentation` | Project ID, funnel ID or event names |
| Amplitude | `funnel`, `retention`, `event segmentation` | Event names, date range |
| Heap | `query` or `report` | Environment ID |
| June, Statsig, GrowthBook | `experiment results` or `metrics` | Experiment or metric ID |

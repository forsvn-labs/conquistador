# Content-performance-review workflow

Use privately for measured organic text, image, carousel, newsletter, or video content.

1. Use `measure-growth` to define one primary platform, source/window, comparable baseline, primary
   outcome, diagnostics, and confounders.
2. Use `improve-conversion` to locate the first evidenced message-to-action break and design one
   next-cycle change.
3. Use `evaluate-shortform` instead when the consequential artifact is an actual short-form video.

Load recovered content-eval method under `conquistador/references/content-performance-review/`
(metric ingest, diagnosis, recommendation, critic) instead of paraphrasing it.

Views, reach, and engagement cannot override failed qualified behavior unless one was explicitly the
primary outcome. Keep platforms, versions, and cohorts separate. Finish with keep/drop/change, one
falsifiable hypothesis, a stop rule, and what evidence would reverse the diagnosis.

End with one terminal Review Packet for final human review: evidence boundary, actual performance
diagnosis, preserved strengths, next-cycle change, and one next action.

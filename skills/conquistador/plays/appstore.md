# Optimize-app-store-listing workflow

Use privately for App Store or marketplace listing search, conversion, and review intelligence.

1. Use `optimize-search` to inspect current store results, query intent, metadata constraints,
   competitors, index/discovery evidence, review language, and measurement.
2. Use `write-copy` for accurate name, subtitle, description, or equivalent listing copy.
3. Use `brief-creative` for a progressive screenshot or preview story grounded in real UI.
4. Use `improve-conversion` to define one listing test and qualified activation guardrail.

Do not invent keyword volume, rank, conversion, product behavior, compatibility, awards, or reviews.
Keep metadata, media, product page, and activation promise congruent. Verify current store constraints
when they affect the work.

End with one terminal Review Packet for final human review: search diagnosis, finished metadata copy,
media story, claim and platform boundary, test rule, and one next action.

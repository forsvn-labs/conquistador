# UGC-style format

Use when a first-person demonstration or reaction is appropriate and the speaker's relationship to the
product is truthful.

- Define the speaker, actual experience, disclosure, audience, and claim boundary before scripting.
- Use natural language and concrete product interaction; do not manufacture a customer identity,
  testimonial, surprise, or before/after result.
- Let imperfections serve comprehension only; fake low production value is still fabrication.
- Show the mechanism and limitations, not only enthusiasm.
- Produce distinct platform recuts and verify the actual render.

If no real authorized user story exists, use a disclosed founder/demo format instead.

# Motion background format

Use when motion supports hierarchy, atmosphere, or product proof behind a primary message.

Make the motion background the user asked for in your own judgment from the user's facts. Load no
other file for it. Then run only the facts check: remove claims the facts do not support, keep fair
inferences, and add nothing (no hedges, no source text, no disclaimers). Return only what the user
asked for.

## Platform facts (checked Oct 2026; confirm in the current specs before use)

- **Accessibility (WCAG 2.2, criterion 2.2.2):** motion that starts on its own and lasts more than 5
  seconds needs a way to pause, stop, or hide it. Honor the reduced-motion setting
  (`prefers-reduced-motion`).

Keep small edits small. Nothing is sent, published, spent, uploaded, or changed in an account
without the user's approval for that exact action. This approval governs actions; it adds nothing to
the deliverable.

# Sequential fallback

Use when the host cannot run a separate context, current browser/tool/provider, render surface, or live
integration that a deeper mode could use.

- Preserve the outcome and authority boundary; reduce machinery, not judgment.
- For contested decisions, produce the strongest counter-position from different first principles,
  then resolve against criteria fixed before the counter-read. Label it single-context, never
  independent corroboration.
- For research, separate primary evidence, secondary evidence, inference, assumptions, conflicts, and
  unknowns; state what a missing provider or source would test.
- For actual-output review without a renderer, inspect every available artifact and return the exact
  acceptance rubric plus the missing proof—do not pretend the render was seen.
- For publishing or integrations without a verified tool, return a validated export and the exact
  human action.

The fallback must still end in one useful terminal Review Packet. Never install a runtime, revive a
router, or manufacture tool success to mimic the unavailable mode.

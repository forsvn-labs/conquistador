# Platform decision-pack contract

Each installed skill carries its own complete pack copies. Load only the selected channel or asset format. These files specify decisions, production checks and tests; they do not certify current platform behavior or predict distribution.

## Evidence and dates

`method_updated` dates the method edit. `last_verified: null` and `verifier: none` mean no platform verification accompanied that edit. Never replace them with a fresh verification date merely because prose changed. The task record must identify the actual account, selected format, primary requirements checked, check date and unresolved capability limits. Missing checks remain visible in the review packet and can block publication.

## Pack contents

The platform slug matches its filename. `pack_type` identifies a shortform-video channel family, launch-channel or asset-format. The existing shortform-video label also covers text and long-form channel choices; select the actual format inside the pack.

- Section 0 makes the fit or defer decision.
- Section 1 offers openings with an explicit evidential payoff, without performance tiers.
- Section 2 owns format verification, accessibility, rights and production handoff.
- Section 3 defines measurement, with account-local denominators and uncertainty.
- Section 4 identifies channel-specific failure modes.
- Section 5 produces an asset, bounded test and review packet.
- Section 6 sets timing from capacity and observation needs.
- Section 7 checks the full action path.
- Section 8 carries unresolved decisions and evidence limits.
- Section 9 records method changes separately from external verification.

## Consumer rules

Creation agents use the pack to make choices and write a testable brief. Critics inspect the delivered claim, evidence, format and action path; catalog membership is not a quality score. Evaluators compare actual artifacts and task-local account evidence, not an alleged ranking hierarchy. Planners reject channels whose audience, access, rights or response requirements cannot be met. Measurement work keeps observed association separate from causal effect.

Preserve pack copies for standalone installations. When editing a shared method, update the corresponding local copies and check their byte equality. There is no assumed remote refresh service, generated source directory or subscription dependency. Existing method metadata is not a release or live-test claim.

# Caption and CTA agent

Produce final text for the selected destination and a usable route to the intended outcome. Read `references/caption-cta-rules.md`, the platform pack and the format specification. Do not import fixed caption windows, hashtag counts or CTA rankings from research.

## Inputs

Use the supported angle, platform/account, market, supplied buyer language, storyboard, format evidence and approved destination. A research example may inform a hypothesis; it does not establish an interface requirement.

## Procedure

1. Write the task or result at the start of the caption, then add necessary context, conditions and disclosures.
2. Check every claim against the brief and source evidence. Do not force a customer quotation where none is authorized or relevant.
3. Count the complete caption using the destination's applicable counting rule. Preview the collapsed view and record the actual visible text.
4. Add relevant topic labels or campaign identifiers only when justified. No fixed number of hashtags is required.
5. Select the next action from the user's goal and the account's actual controls. Check the full route and terms; document any additional taps or reply work.
6. Give the producer exact text and placement for the caption, overlay, end frame or response where the CTA appears.

## Output contract

For each destination, return Caption text, Caption length with verified cap or pending check, First-visible text from preview, optional Hashtag block with rationale, and Caption rationale.

Return CTA type, exact copy, placement/time, destination, access conditions, tracking if used and rationale. Include the source of account capability verification, pending checks and a Change Log. The primary caption belongs here; platform-tailor-agent assesses complete variants.

## Acceptance

The asset and caption must make the same supported promise. Essential disclosure must remain available. The CTA must identify an actual next step with clear value; no assumed reach penalty dictates link placement. A draft with unknown limits can be reviewed as a draft but cannot be represented as upload-ready.

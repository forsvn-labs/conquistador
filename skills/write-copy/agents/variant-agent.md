# Create interpretable copy alternatives

## Input contract

Receive the approved brief, assembled draft, product facts, offer terms, and the decision the proposed test should inform.

## Procedure

Choose a unit whose alternative could resolve the stated question. Explain what changes and what remains fixed. A wording synonym is not a useful alternative unless that distinction matters to the audience.

Draft the alternative from the same factual basis. Do not make one version more attractive by inventing a discount, guarantee, customer result, or feature. Review both versions with [copy review](../references/copy-review.md).

If an experiment is requested, specify the eligible audience, destination, useful action, window, and source of measurement. Identify changes in traffic or delivery that could prevent interpretation. The skill can propose the test; it does not execute it or establish significance.

## Output contract

Return original, alternative, hypothesis, changed element, protected facts, and review status. Recommend a test order based on consequence and uncertainty. Do not assign a fabricated winning probability or certify a winner from editorial preference.

Without a test request, deliver only alternatives that offer a meaningful choice. Publishing and paid distribution remain human-owned.

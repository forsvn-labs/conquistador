# Format copy for handoff

Use the user's requested format. Keep finished copy separate from editorial notes so the reader can paste the intended unit without reviewer instructions.

For a saved Markdown artifact, include skill, date in YYYY-MM-DD form, surface, audience, and draft status. Choose a descriptive filename that contains no private customer identifier unless the user requested and authorized it. Preserve an existing file unless replacement is explicitly intended.

Organize the body by actual page or message order. Identify headlines, body blocks, and action labels clearly. Keep source notes outside public copy unless an attribution or disclosure belongs in the published material.

For variants, record the changed unit, hypothesis, and protected facts. For review, record location, defect, correction, and any missing evidence. Use PASS or REVISE as an editorial status according to [copy review](copy-review.md), never as publication authority.

Use exact supplied names, numbers, URLs, and offer terms. Flag placeholders visibly. Do not encode unavailable evidence as a numerical score. Preserve output language and brand voice constraints from the brief.

Before handoff, confirm that the receiving skill or person can distinguish finished copy, alternatives, and unresolved decisions without reading the chat history.

# Diagnostic review failures

Use these checks with the [critic](../agents/critic-agent.md). Correct the inference or missing evidence rather than adding formal structure to make the diagnosis appear complete.

| Failure | Why it changes the decision | Correction |
|---|---|---|
| Target treated as baseline | Missing a target does not prove the system worsened | Show the observed comparison separately from the aspiration |
| Unchecked measurement | Collection or eligibility changes can affect the reported difference | Compare definitions and available independent records; keep residual uncertainty |
| Equation treated as causal proof | Factors in an identity can share causes and interact | Separate accounting terms from hypotheses and retain interactions |
| Forced independent branches | Real causes can affect several factors or overlap in records | Map dependencies and choose a non-overlapping accounting allocation only where justified |
| Exhaustive-coverage claim | Unlisted causes may remain plausible | State omitted scope and unresolved alternatives |
| Fixed tree depth or type | Diagram shape can consume effort without producing a useful observation | Stop at a discriminating check; use a table or equation when clearer |
| Timeline used as confirmation | Co-timed changes can predict the same movement | Compare exposures, populations, controls or other evidence that distinguishes candidates |
| Aggregate interpreted without mix | Changing segment weights can move a blended rate | Recalculate segment rates and weights under consistent definitions |
| External event assumed causal | A documented event may not affect this population | Record exposure, mechanism and competing predictions |
| Hypothesis quota | Extra candidates can duplicate the same explanation | Include material alternatives; justify exclusions |
| Source placeholder treated as evidence | A named tool is not an inspected result | Preserve location, access status, owner and missing-data request |
| Unsupported gap percentages | Speculative shares can misdirect the next initiative | Mark estimates and unknowns; reconcile only compatible quantities |
| Premature closure | A rejected hypothesis does not establish a replacement | Return Inconclusive or an undetermined cause with one useful next check |
| Diagnosis triggers execution | Analysis does not supply authority to change a live system | Propose the check and preserve the existing action boundary |

Preserve the phase headers, hypothesis fields, verdict values, external-factor records and Next Step handoff from [format conventions](format-conventions.md). The coverage section records dependencies and limits; it does not certify an imported decomposition model.

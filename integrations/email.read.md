# email.read

Read inbox threads, campaign and broadcast results, lists, and audience segments.

## Answers

- How did the last campaigns perform on opens, clicks, and unsubscribes?
- What do prospects reply, and which objections repeat?
- How large is each list or segment?

## Find the tool

Search phrases: `search email messages`, `list email campaigns`, `email campaign report opens clicks`.

Search with a narrow query and a date window. Summarize threads; do not paste message bodies
into deliverables.

## Providers

| Provider | Search for | Needs |
| --- | --- | --- |
| Gmail | `users messages list` with `q`, then `messages get` | Gmail search query (`from:`, `after:`) |
| Mailchimp | `campaigns list`, `reports get` | Campaign ID |
| Customer.io | `campaigns metrics`, `broadcasts metrics` | Campaign or broadcast ID |
| Resend | `emails get`, `broadcasts list` | Email or broadcast ID |
| Loops | `contacts find`, `lists` | Email or list ID |
| Kit, Beehiiv | `broadcasts stats`, `posts stats` | Publication ID |

# docs.read

Read documents, pages, and files from the team's docs and drives.

## Answers

- What do existing briefs, research notes, and positioning docs already say?
- Which voice samples, proof points, and assets exist?

## Find the tool

Search phrases: `search documents`, `get page content`, `list files in drive`.

## Providers

| Provider | Search for | Needs |
| --- | --- | --- |
| Notion | `search`, `pages retrieve`, `blocks children list` | Query or page ID |
| Google Drive | `files list` with `q`, `files export` | Query; export MIME type for Docs |
| Confluence | `search` (CQL), `pages get` | Space key or CQL |
| Dropbox, Box | `search`, `download` | Path or file ID |
| GitHub | `repos contents get`, `search code` | Owner, repo, path |
